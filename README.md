# swift-growth-engine

SwiftGrowthDigital's existing Vite + React website with Supabase Edge Functions and Postgres.

## Local development

- `npm install`
- `npm run dev`

## Build and checks

- `npm run build`
- `npm run lint`
- `npm test`
- `npm run preview`

## WhatsApp Cloud API

The production integration, Supabase migrations, deployment steps, Meta configuration, admin access, and campaign scheduler setup are documented in [docs/WHATSAPP_CLOUD_API.md](docs/WHATSAPP_CLOUD_API.md).
